# VibeCheck 🛡️

VibeCheck は、Google Gemini AI (Flash Model) を活用して X (旧Twitter) のタイムラインから「見たくない投稿」を自動的にフィルタリングする Chrome / Edge 拡張機能です。

ブラウザ側でテキストを解析し、ヘイトスピーチ、過度な攻撃性、スパム、またはあなたが指定した特定の話題を含むポストを視覚的に遮断（Default Deny）します。

## ✨ 主な機能

* **AIフィルタリング**: Gemini 2.5/1.5 Flash を使用した高速・高精度な文脈判定。
* **Default Deny**: 判定中は内容を隠し、安全が確認されたものだけを表示（チラつき防止）。
* **広告ブロック**: プロモーションツイートをAI消費なしで即時ブロック。
* **ホワイトリスト**: 信頼するユーザー（推し・公式など）をスキャン対象外に設定可能。
* **学習機能 (Few-Shot)**: 「このツイートが嫌い」をボタン一つで学習させ、あなた好みの判定基準へ進化させることができます。

## 🚀 ビルドとインストール手順

この拡張機能はストア公開前の開発版です。以下の手順でローカルビルドしてブラウザに読み込ませてください。

### 1. 前提条件
* Node.js (v18以上推奨)
* npm (Node.jsに同梱)

### 2. リポジトリのクローンと依存関係のインストール

```bash
git clone <このリポジトリのURL>
cd vibe-check

# 依存パッケージのインストール
npm install
```

### 3. ビルド (TypeScript -> JavaScript)
TypeScriptのソースコードをブラウザが理解できるJavaScriptにコンパイルします。

```bash
# ビルド実行
npx tsc
```

エラーが出ずに終了すれば成功です。プロジェクトルートに dist/ ディレクトリが生成され、その中に .js ファイルが出力されます。

### 4. ブラウザへの読み込み

**Google Chrome の場合**
1.  アドレスバーに `chrome://extensions` と入力して開く。
2.  右上の **「デベロッパーモード」** スイッチをオンにする。
3.  左上の **「パッケージ化されていない拡張機能を読み込む」** をクリック。
4.  このプロジェクトのルートフォルダ（`manifest.json` があるフォルダ）を選択する。

**Microsoft Edge の場合**
1.  アドレスバーに `edge://extensions` と入力して開く。
2.  左メニューの **「開発者モード」** をオンにする。
3.  **「展開して読み込む」** をクリック。
4.  このプロジェクトのルートフォルダを選択する。

5.  ## 🛠️ 開発者向け情報

ソースコードを変更しながら開発する場合、以下のコマンドでファイルの変更を監視して自動ビルドできます。

```bash
npx tsc --watch
```

⚠️ 注意: 拡張機能のコード（特に content.ts や background.ts）を更新した後は、以下の2ステップが必要です。

1. ブラウザの拡張機能管理画面で「更新（リロード）」ボタンを押す。
2. Xのページをリロード (F5) する。

**6. プライバシーとライセンス**

## 🔒 プライバシーについて

* **ローカル処理**: APIキーや設定情報、学習データは、お使いのブラウザのローカルストレージ (`chrome.storage.local`) にのみ保存されます。
* **データ送信**: ツイートのテキストデータは判定のために Google Gemini API に送信されますが、開発者（リポジトリ管理者）のサーバー等に送信されることはありません。
